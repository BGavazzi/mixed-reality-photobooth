# Mixed-Reality Photo Booth (web_server.py) -- the primary demo.
#
# This file alone is enough to run it, on Windows, macOS or Linux, with no
# follow-up commands. Optional pieces live in their own files so nobody has
# to install a Windows-only package to try the browser app:
#
#     requirements.txt            <- you are here (photo booth)
#     requirements-resolume.txt   <- Resolume/OSC bridge + Spout output
#     requirements-backends.txt   <- hosted generation backends (Runway, Kling)
#     requirements-test.txt       <- the offline test suite
#
# Not listed but pulled in automatically: torch, torchvision, timm, scipy,
# scikit-image (via controlnet_aux). That's most of the ~2GB download and
# most of the install time -- expect several minutes on a cold cache.
#
#     python doctor.py     <- checks all of this and says what's missing

# web layer
fastapi
uvicorn[standard]
websockets
python-multipart          # FastAPI needs this to declare the upload route at all
requests

# imaging / CV
Pillow
numpy
opencv-python-headless    # see the note at the bottom before "fixing" this
matplotlib                # undeclared dependency of controlnet_aux: its OpenPose
                          # hand renderer imports it inside draw_handpose(), and
                          # estimate_pose() calls that with include_hand=True

# the analysis models (weights download themselves on first use)
rembg                     # rotoscope (birefnet-portrait)
onnxruntime               # rembg's runtime
controlnet_aux            # OpenPose + MiDaS

# --- about opencv ------------------------------------------------------------
# controlnet_aux hard-depends on opencv-python-headless, and both that and the
# GUI build install the same importable `cv2` -- whichever lands last on disk
# wins. This file therefore asks for headless *deliberately*, so the two never
# fight: the photo booth only uses cv2 for array work (connected components,
# colour conversion), which headless does perfectly.
#
# The GUI build is needed by exactly one optional file, spout_viewer.py, which
# calls cv2.imshow/waitKey. requirements-resolume.txt handles that case; if you
# don't run the Spout viewer, you never need it, and the
# `pip install --force-reinstall opencv-python` step this project used to
# require is now gone from the main path entirely.
